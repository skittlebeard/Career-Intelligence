# Claude installation and use
## Preferred: Claude Skills (where supported)
1. Keep the package folder structure intact and zip the career-intelligence directory.
2. In Claude's Skills/customization area (availability and exact labels vary by plan/workspace), upload/install the ZIP if skill uploads are supported. Review any permission or execution prompts. Verify that SKILL.md and its supporting files are visible to the skill.
3. Start a chat or project with web research and file-creation tools enabled where available; attach resume and optional contacts CSV. Request the skill by name.
4. Ask for the consolidated report and JSON snapshot; download both and provide the snapshot on the next run.
## Fallback: Claude Project
Create a Project, place SKILL.md in project instructions (or upload as knowledge if too long), and upload all supporting markdown/schema/template files as project knowledge. Confirm the model can access those files. Skills and Projects are not identical; a Project does not guarantee automatic skill activation.
## Limitations
Live open-job verification depends on actual browsing access and the site. Contact exports are optional. Claude does not automatically retain a portable run history: keep and reupload snapshots. Test with one real resume and check five random cited claims and each job link. UI labels and availability may change; consult current Anthropic documentation.
