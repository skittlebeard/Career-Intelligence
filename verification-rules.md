# Job verification and lifecycle
Verified open requires an accessible employer-controlled careers page or authoritative ATS posting showing an apparently active position at inspection time. Record canonical URL, employer, title, job ID if available, verified_at in UTC, and status=verified_open. A job aggregator, search result snippet, stale cache, expired page, or recruiter repost alone cannot satisfy this. If a job page is accessible but its active state is ambiguous, status=unverified and exclude from ranked verified results. Never guess posting date from crawl date. Compensation is null if not published; do not estimate as employer fact. On reruns distinguish confirmed_closed (explicit closed/removed by authoritative source) from no_longer_verified (404, auth error, redirect, or transient failure). Keep historical evidence and last_verified_at. Detect duplicate listings across locations and ATS mirrors by employer+job ID first, then canonical URL/title/location cautiously. When tools cannot browse or verify, return a research plan, not fabricated verified openings.
