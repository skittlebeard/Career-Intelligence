# ChatGPT installation and use
## Recommended: reusable Custom GPT or a connected Work workflow
1. Open GPT creation/configuration if your plan/workspace supports custom GPTs.
2. Name it Career Intelligence Agent; copy SKILL.md into its Instructions, keeping essential guardrails intact. Upload the remaining .md and JSON schema/template files to Knowledge (subject to current upload limits). If instructions exceed limits, put detailed methodology in Knowledge and instruct the GPT to read the named files.
3. Enable web search and file/data analysis tools where available. Verify the configured GPT can access both and cite actual sources.
4. Upload resume/skills and optional LinkedIn CSV per run. Request one consolidated document plus machine-readable snapshot. Save and reupload snapshot to compare runs.
5. For multi-step research, ChatGPT Work may be more appropriate when available; provide the same package as task instructions and inputs. A custom GPT is not itself an autonomous scheduled agent.
## Alternative: private plugin
If you maintain a private ChatGPT plugin, incorporate these files as its skill/instructions and implement the same schema. Plugin installation, capabilities and permission scopes depend on the workspace.
## Limitations
Live verification requires browsing, file generation requires enabled tools, and repeatable comparisons require retained snapshots or approved storage. Do not assume LinkedIn integration or contact access. UI labels and availability change; verify current OpenAI help guidance before installation.
