# Candidate profile extraction
Preserve original file untouched. Assign each capability status: demonstrated (resume achievement/role proof), declared (skills list only), transferable (reasoned analog), unknown. Record source text reference and confidence. Distinguish hands-on delivery, architecture, leadership, ownership, advisory, exposure. Infer role families provisionally from career history, but do not assume desired seniority. Treat certifications and degrees as present only if explicitly supplied. Store candidate_id as a locally assigned non-sensitive pseudonym. Identify mandatory constraints only if explicitly provided. Resume gap analysis must use exact source achievements and may propose phrasing without increasing scope, budgets, tenure, certifications or outcomes. Never include sensitive demographic attributes in scoring.
